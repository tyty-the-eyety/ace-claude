## Salesforce node Requirements

1. Request nodes: `xmi:type="ComIbmApplicationConnectorRequest_salesforce.msgnode"`, `applicationConnectorType="salesforce"`
2. Input nodes: `xmi:type="ComIbmApplicationConnectorInput_salesforce.msgnode"`, `applicationConnectorType="salesforce"`
3. The Request node **MUST** also have `schemaPrefix="gen/<FlowName>.Salesforce_Request"` — create `<FlowName>.Salesforce_Request.request.schema.json` and `<FlowName>.Salesforce_Request.response.schema.json` in the `gen/` subdirectory per the connector general rules in SKILL.md.

## Policy XML example

Name the policy file `Salesforce1.policyxml` (or as chosen). Example:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<policies>
  <policy longDescription="" policyName="Example" policyTemplate="online_v1_basic_jwt" policyType="salesforce" shortDescription="" version="">
    <credentialName>SalesforceCredential</credentialName>
    <applicationVersion>v1</applicationVersion>
    <applicationType>online</applicationType>
    <authenticationMethod>BASIC_JWT</authenticationMethod>
    <endpointUrl>https://login.salesforce.com/</endpointUrl>
    <domainName/>
    <proxyId/>
    <apiVersion>54.0</apiVersion>
   </policy>
</policies>
```
Policy file structure MUST conform to the ACE Policy XML schema; optionally verify against `<ACE_INSTALL_DIR>/common/schemas/Policy/Policy.xsd`.
